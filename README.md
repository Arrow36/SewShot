# SewShot · 截图拼接

在浏览器本地把连续截图接成完整长图。支持自动识别重叠、手动调整接缝、逐图裁剪，以及 PNG / JPG 和分段导出。浅绿色界面，采用「选择截图 → 拼接 → 导出」三步操作。

**在线使用：[arrow36.github.io/SewShot](https://arrow36.github.io/SewShot/)**
**发布与维护：[@Arrow36](https://github.com/Arrow36)**

## 功能

- 导入 PNG、JPG、WebP；支持纵向与横向拼接。
- 保留文件选择器返回的顺序，可用按钮或拖动调整顺序。
- 自动识别相邻图片的重叠，高置信匹配直接应用；不确定的接缝保留完整内容，交由用户确认。
- 纵向拼接默认自动裁剪上下浏览器信息栏，逐张识别展开、收起时不同的高度；可关闭恢复信息栏。
- 对带有分隔线、且在上一张正文内找到完整对应的悬浮标题栏，自动去除重复标题。
- 在预览中直接编辑：调整重叠、裁切原图边缘、撤销与重做。
- 拼接及裁剪预览从原图渲染当前可见区域，按屏幕像素密度生成高清画布；原图解码缓存最多保留 3 张。
- 固定页面布局，禁用双指、双击及触控板缩放，保留单指滚动与裁剪手柄拖动。
- 返回上一步保留图片、顺序和已确认编辑。
- 导出无损 PNG 或可调质量 JPG，支持原尺寸、缩小与分段图片。
- 浏览器支持时提供系统文件分享。

## 使用方法

1. 点击「上传」选择连续截图。返回首页后，点击「继续处理」回到已选截图。
2. 检查图片顺序，选择纵向或横向。纵向默认勾选「自动裁剪上下信息栏」，点击右箭头后先检测信息栏，再识别重叠。
3. 等待自动匹配。点击图片或接缝标记进行调整，使用勾号确认编辑。
4. 点击右箭头进入导出。默认 PNG、原尺寸；设置图标中可切换格式、尺寸与分段导出。
5. 点击「保存」生成结果，再点击下载链接；支持的设备也可使用系统分享。

若有待确认接缝，可返回调整，或勾选「保留重复内容」导出完整来源内容。该选项表示接缝尚未确认，并不表示程序已经检测到重复。

## 隐私与运行方式

图片解码、匹配、裁剪和导出均在浏览器内完成。应用不上传图片，不使用第三方 CDN、分析脚本或后端服务，也不把任务写入持久存储。刷新或关闭页面后任务不会保留。

访问在线页面时，GitHub Pages 会提供静态网页资源；点击系统分享后，文件由用户选择的目标应用接收。

## 当前限制

这是可交互的早期版本，尚未完成大规模截图素材和手机真机兼容性验证。

| 项目 | 当前范围 |
| --- | --- |
| 每个任务 | 最多 30 张截图 |
| 单张文件 | 不超过 25 MiB、2400 万像素 |
| 纵向拼接 | 截图宽度一致 |
| 横向拼接 | 截图高度一致 |
| 完整长图导出 | 最多 1400 万像素，最长边不超过 16384 px |
| 分段导出 | 每段沿拼接方向最多 4096 px；横截面不超过 8192 px，且横截面 × 4096 不超过 1400 万像素 |
| 安装与恢复 | 暂无 PWA 安装、离线缓存及任务恢复 |

自动信息栏裁剪适用于至少两张纵向截图，要求共享背景特征、明确边界和控件细节；识别不可靠时保留内容。单张或横向截图请使用手动裁剪。透明导航栏、主题变化、动态内容、缩放不一致、纯色区域与重复纹理仍可能需要手动裁切或对齐。超出导出预算时，请缩小尺寸或选择分段。系统文件选择器可能不提供实际勾选先后顺序，导入后请检查排序。

## 本地运行

无需安装 npm 包或构建。使用 Python 3 启动静态服务器：

```sh
git clone https://github.com/Arrow36/SewShot.git
cd SewShot
python -m http.server 8766 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8766/>。建议通过本地 HTTP 或线上 HTTPS 访问，以使用浏览器的 Worker 等能力。

使用 Node.js 18 或更新版本运行核心测试：

```sh
node --test tests/core.test.cjs
```

现有 19 项测试覆盖重叠计算、裁切组合、横向坐标、纯色与重复纹理拒绝、精匹配、稀疏文字匹配、可变高度信息栏及悬浮标题栏检测。

另外通过浏览器验证三张 1206 × 2622 的真实手机截图：识别不同高度的上下信息栏与悬浮标题，两处重叠自动拼接，导出 1206 × 5297 PNG。测试原图不随仓库发布。

## 技术结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 三步界面、图标和编辑对话框 |
| `style.css` | 响应式布局与样式 |
| `app.js` | 图片导入、Worker 信息栏检测与粗匹配、精校验、可见区域高清预览及 Canvas 导出 |
| `core.js` | 信息栏检测、匹配、精校验、序列规划和裁切坐标计算 |
| `icon.svg` | 本地站点图标 |
| `tests/core.test.cjs` | 核心算法回归测试 |

匹配先对灰度图片降采样寻找候选，再保留原始滚动轴分辨率校准重叠，精校验的横向采样最多为 320 px。稀疏内容采用更严格的像素误差、梯度相关性与候选差距要求。实际交互只匹配当前顺序中的相邻图片，不自动重排。

## GitHub Pages 部署

仓库通过 GitHub Pages 发布 `main` 分支根目录，`.nojekyll` 使站点按静态资源提供，无需构建。后续提交推送至 `main` 后，GitHub Pages 会更新站点。
